## Projects

### Restaurant Operations Suite

**Central Warehouse Management System**
- Tracks a shared central warehouse across four outlets
- Cash reconciliation across two separate registers
- Outlets submit stock orders via a Telegram bot; orders are routed automatically into the system
- Integrates with a 1C:Enterprise point-of-sale environment
- Multi-tenant ready: each client receives a dedicated site and an isolated database

**Payroll Management Systems**
- Two payroll applications built on a shared code base
- Attendance, work schedules, bonuses and penalties
- Per-employee carry-over of outstanding balances
- Employee archiving instead of deletion, date-based search, password-protected access
- Role-based access control: administrators have full access; managers record attendance and onboard staff without visibility of salary data

**Receipt Cancellation Audit**
- Daily AI-assisted workflow that aggregates POS receipt cancellations by section into a structured Excel report

### Tea House Management Application

- Manages tables, orders, menu, inventory, purchasing and expenses
- Mobile-first web app built on Firebase and Netlify
- PIN-secured owner access; staff attendance and daily pay tracking
- Automated daily report delivered to Telegram via GitHub Actions — triggered on shift close or as a scheduled fallback
- Custom business-day logic for operating hours that extend past midnight

### Workflow Automation with n8n *(in progress)*

- **News Digest Bot** — collects top world headlines from RSS sources each morning, translates them into Azerbaijani with an LLM and publishes them to Telegram
- **YouTube Content Pipeline** — generates a complete video (voice-over and visuals) from a topic submitted via Telegram and uploads it to YouTube

### Airport Operations Analytics

- Integrated six datasets — flight operations, ticketing, passenger services, maintenance, HR and finance
- Cleaned and linked the data in Power Query using Flight ID as the key
- Delivered an analytical report on the unified data model
